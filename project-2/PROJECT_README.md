# Task Management Application

A full-stack task management web application built for Project 2 of the internship. Users can register, log in, create tasks, update task status, edit task details, delete tasks, and filter tasks by status or priority.

## Features

- User registration and login
- JWT authentication and protected task APIs
- Create, read, update, and delete tasks
- Task status tracking: To Do, In Progress, Done
- Priority levels: Low, Medium, High
- Search and filters
- MongoDB database storage
- Responsive React dashboard

## Tech Stack

- React.js
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT

## Run Locally

Backend:

```bash
cd backend
npm install
npm start
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```

Open:

```text
http://127.0.0.1:5173
```

The backend runs on:

```text
http://127.0.0.1:5001
```
